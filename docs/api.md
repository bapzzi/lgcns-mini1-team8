# 화면과 서버가 주고받는 값

> 팀장 초안 틀입니다. 조각을 고른 뒤 각 담당이 채웁니다. 이 파일이 규격의 단일원천입니다. 화면 담당과 서버 담당이 **같은 문장을 말할 수 있어야** 다음 단계로 갑니다.
> 바꾸려면 `CONTRIBUTING.md`의 "규격을 바꿔야 할 때"를 따릅니다.
