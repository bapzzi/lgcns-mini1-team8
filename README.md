- **UI 와이어프레임(Figma)**: https://www.figma.com/design/PXMMTbObThkRVGTRwM9Gxh/Figma

## 무엇을 만드나 (초안, 9/18 회의에서 확정)

입력한 정보에 맞는 채용공고를 찾아 주고, 그 기업의 기술블로그를 어떻게 읽으면 좋을지 AI가 안내하는 기업 준비 가이드.

메인 흐름: 로그인 → 기본정보 입력 → 추천 공고 목록 → 공고 상세 → AI 가이드

## 기술 스택

| 영역 | 기술 | 근거 |
|---|---|---|
| 화면 | React | 운영진 공지(미니 PJT 1 기술) |
| 서버 | Spring Boot | 운영진 공지 |
| DB | MySQL | 운영진 공지 |
| AI | 생성형 AI API | 서비스 미정 |

버전은 미정입니다. Docker는 쓰지 않는 방향으로 논의 중입니다.

## 실행 방법

```bash
# 1. 받기
git clone https://github.com/bapzzi/lgcns-mini1-team8.git
cd lgcns-mini1-team8
git checkout develop

# 2. 환경 변수
cp .env.example .env
# .env를 열어 값을 채웁니다. .env는 커밋하지 않습니다.

# 3. 실행
[골격 PR에서 정한다]
```

처음 받은 사람이 이 문단만 보고 실행하지 못하면 문서가 틀린 것입니다. 고친 사람이 이 칸도 같이 고칩니다.
